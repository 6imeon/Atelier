Design System Panel — 5 Explorations

Each exploration reimagines the design system panel with the two-layer architecture: Active Tokens (from generated pages) as the primary controls, with Original Site Reference as a collapsible secondary layer.

Option A

Layered Stack

Two distinct layers with tab switching: Active (green badge) shows the generated page's actual tokens that you control. Reference (amber badge) shows the original site extraction.

Color rows have shade strips for quick variant selection. Sync status bar shows live binding health — green means all values match the screens.

  • Active/Reference tab switching
  • Shade gradient strips per color
  • Live sync status indicator
  • Inline hex editing
  • Binding health feedback

Option B

Spectrum View

Color-centric design with a rotating conic gradient wheel. Palette dots orbit the wheel at their hue positions. Harmony mode selector (Complementary, Analogous, Triadic, Split) reshapes the palette relationships.

Typography shown as large card previews with actual font rendering. Everything feels like a living color space.

  • Animated color harmony wheel
  • Draggable hue dots on wheel
  • Harmony mode switching
  • Large type preview cards
  • Color usage annotations

Option C

Token Inspector

Developer-focused view showing tokens as key-value pairs with live binding status. Each token shows whether it's actually bound to the screen HTML (green dot) or disconnected (red dot).

Code block at the bottom shows CSS custom properties. Binding health bar shows percentage of tokens that actually match the generated pages.

  • Live binding indicators per token
  • CSS variable code preview
  • Binding health percentage bar
  • Screen-specific token display
  • Monospace aesthetic for precision

Option D

Story Mode

Narrative-driven design system that tells the story of the redesign. Opens with the persona's design philosophy as a quote. Colors are presented as a "palette story" with each color's emotional meaning. Typography shown as a live pairing preview.

Includes the proposed page plan at the bottom. Feels like reading a design brief, not just tweaking values.

  • Persona quote and design ethos
  • Color meaning annotations
  • Live type pairing preview
  • Proposed page plan
  • Editorial, brief-like feel

Option E

Spatial Canvas

Design tokens as draggable objects on a mini-canvas with dot grid. Colors are swatches, fonts are text samples, radius is a shape — all connected by dashed lines showing relationships.

Bottom toolbar lets you apply tokens, export as CSS, or inspect binding. Collapsible "Original Site" reference at the bottom. Feels like the main canvas but for tokens.

  • Draggable token objects
  • Relationship connection lines
  • Mini-canvas with dot grid
  • Collapsible original site ref
  • Apply / Export / Inspect toolbar
